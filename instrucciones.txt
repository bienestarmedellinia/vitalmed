INSTRUCCIONES - Medellín, Bienestar Basado en Datos
Equipo: [NOMBRE DEL EQUIPO] · Hackathon de Datos 2026

1. QUÉ ES
   Pipeline automático que descarga datos oficiales de la Encuesta de Calidad
   de Vida (ECV) de Medellín y de calidad del aire (SIATA), valida su
   consistencia territorial, los homologa e integra en una tabla agregada por
   comuna y corregimiento. Todo corre sin intervención manual en GitHub Actions.

2. PROBARLO EN LÍNEA
   Pestaña "Actions" del repositorio -> workflow "pipeline-ecv" -> "Run workflow".
   El resultado queda como artefacto descargable "resultados-ecv".

3. ENTORNO
   Lenguaje: Python 3.11
   Dependencias (ver requirements.txt, versiones fijas):
     pandas==2.2.3 · openpyxl==3.1.5 · requests==2.32.3 · PyYAML==6.0.2 · pyarrow==17.0.0

4. EJECUTARLO
   pip install -r requirements.txt
   python scripts/01_descargar.py
   python scripts/03_validar.py
   python scripts/02_limpiar.py
   python scripts/04_integrar.py
   (o, de forma automática: ejecutar el workflow .github/workflows/pipeline.yml)

5. QUÉ DEBE VER
   - El paso de validación imprime "VALIDACIÓN OK: llave territorial consistente".
   - Se genera outputs/tablas/resumen_territorial.csv con los registros
     encuestados por comuna/corregimiento y año (16 comunas + 5 corregimientos).
   - Se genera data/raw/_manifiesto_descarga.json con la procedencia (URL + sha256).

6. DATOS Y FUENTES
   - ECV · Encuesta de Calidad de Vida (microdatos) · Alcaldía de Medellín
     https://www.medellin.gov.co/es/centro-documental/encuesta-calidad-de-vida/
     Licencia: Datos abiertos - Alcaldía de Medellín
   - SIATA · Datos validados de calidad del aire · Valle de Aburrá
     https://siata.gov.co/IDEAM/
   - MEData · Datos abiertos de Medellín (conjunto obligatorio)
     https://medata.app.medellin.gov.co/
   Los microdatos NO se incluyen en el repositorio; el pipeline los descarga
   desde la fuente. Solo se publican tablas agregadas, sin datos personales.
